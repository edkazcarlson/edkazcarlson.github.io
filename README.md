# edkazcarlson.github.io

Personal portfolio of Edward Kazuya Carlson, featuring Indexer.

Live site: https://edkazcarlson.github.io/

## Publishing

This repository contains plain HTML, CSS, JavaScript, and image assets. No build step or package installation is required. GitHub Pages should publish `main` from the repository root (`/`). The `.nojekyll` file serves the files directly.

Changes pushed to `main` are published automatically once Pages is enabled.

## Project pages

- `index.html`: portfolio homepage.
- `projects/indexer/index.html`: Indexer overview.
- `assets/`: shared styles, scripts, and real application screenshots.
- `projects/indexer/snapshots/2026-10-04/`: the preserved October 4 development edition, including its own assets, evidence manifest, publication record, and SHA-256 checksums.

The snapshot was first publicly published through Sites on October 5, 2026. Its original bytes and publication record are preserved here. Earlier milestone timestamps are local repository history, not independently verified public disclosure dates. Create a new dated snapshot for later development states rather than changing the existing edition.

## Local preview

Run `python -m http.server 4178` from this directory, then open http://localhost:4178/.

Indexer screenshots were captured using disposable PPE profiles and public sample images. The production Indexer database was not opened or copied. Image attribution is in `assets/image-credits.txt`.
